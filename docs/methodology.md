# Methodology Summary (<=200 words)

Pramaan is a Proof-of-Work Graph that sits beneath Redrob's Resume Ranker as a trust layer. The insight: the Ranker scores resume text, so it rewards keyword-stuffers and misses honeypots. Pramaan never scores profile text — it scores the evidence the profile points at. Per claimed skill, an agent loop runs: RESOLVE the candidate's real artifacts (GitHub, deploys, writing); FETCH evidence via GitHub API, Playwright liveness, Jina Reader, and Exa; RECONCILE — the LLM reasons over retrieved evidence only to decide if the claim holds inside its claimed time window; ATTRIBUTE forked-vs-authored, flag (never auto-reject) AI-generated code, and reconcile timelines (the honeypot kill-shot); EMIT an Evidence Card {skill, verdict (verified/unverified/contradicted), confidence, cited_artifacts, plain_language_reason}. Stack: Next.js + Vercel AI SDK on Vercel, LLM via OpenRouter. Inference is cheap by design: fetching is mostly free, the model sees only distilled evidence summaries, easy verdicts route to small models, and results cache by artifact hash — cents per candidate. Impact metrics (honeypot catch rate, keyword-stuffer precision, false-flag rate, recruiter time-to-trust, cost) are framed as instrumented targets. The moat is asymmetry: provenance is cheap to verify, expensive to fake.
